The models

Every model has hidden size 2048, 16 layers, sequence length 4096 and the same compute per token. gN splits the experts N times finer and sends each token to N experts, so network traffic grows N times while compute stays fixed.

Training throughput, baseline

Tokens per second per GPU, mean of the last 5 of 15 steps. Experts are spread over all GPUs (EP = 4 × nodes). Hover a column for exact values.

Relative to 1 node

Same runs, each model divided by its own 1-node speed. Below 1.0 means the run lost speed by being spread over more nodes.

What this shows

  • Finer experts are slower even on one node. g16 reaches 6,100 tok/s/GPU against 21,100 for g2. The network is fast there, so this is GPU inefficiency: the baseline has no grouped GEMM and runs each GPU's experts one after another.
  • Across nodes, finer experts lose more. From 1 to 8 nodes g4 drops to 0.73×, g8 to 0.63×, g16 to 0.65×. This is the communication effect the project is about.
  • 2 nodes is slightly faster than 1 for MoE. Each GPU holds half as many experts, so its expert loop is shorter. Another sign the baseline is dominated by that loop.
  • Dense dips at 4 nodes (27,900) but recovers at 8 (34,100). Likely noise or node placement; to rerun.
  • The baseline mixes two effects. The next sweep enables grouped GEMM everywhere, so the remaining multi-node drop isolates the network.
